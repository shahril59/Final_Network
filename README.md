# Final_Network
## 📌 Project Overview

This project focuses on designing and implementing a scalable enterprise network architecture using Cisco Packet Tracer. IP address allocation was meticulously planned using Variable Length Subnet Masking (VLSM) to optimize address space and reduce subnet waste.

---

## 🛠️ Network Features & Configurations

- **VLSM IP Planning:** Efficient IP addressing scheme designed to accommodate various departmental host requirements.
- **VLAN Segmentation:** Logical separation of network traffic across different departments for improved performance and security.
- **Inter-VLAN Routing:** Configured router-on-a-stick / Layer 3 switching to enable controlled inter-departmental communication.
- **Security & Access Control (ACLs):** Implemented Standard and Extended Access Control Lists to restrict unauthorized access to critical network resources and servers.

---

## 💻 Tools & Technologies

- **Simulation Tool:** Cisco Packet Tracer
- **Protocols & Concepts:** VLSM, VLANs, Inter-VLAN Routing, ACLs, Subnetting, Network Security
